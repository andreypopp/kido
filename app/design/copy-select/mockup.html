Design proposal, nothing is sent. Copy mode gains mouse selection (drag, double-click word, triple-click line, Shift-click extend) in the accent selection color. Right-click (also on empty cells, for the existing selection) opens a native NSMenu with Copy and Prompt with Selection…; p in copy mode does the same. The prompt box sits at the bottom-left of the pane in the pane capsule style: a target popup (window agents first, then the session; absent with “No agent in this window or session”), a growing text field (Enter sends, Shift-Enter newline), the quoted selection below it, status and Send. Delivery closes the box, clears the selection and exits copy mode. The text is sent as the prompt, a colon, and every selection line prefixed “> ”.
