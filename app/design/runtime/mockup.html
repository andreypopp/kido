Runtime indicator · stripe, row suffix, ⌘P

Decided (user): every pane that executes in a runtime, a routed pi's host pane included, carries a 3pt stripe across the top of its chrome in the runtime's colour and a small pill with the name at the toolbar's corner; the band is reserved only for runtime panes, so their grid starts 3pt lower than a host pane's beside it. The sidebar row repeats the name, dimmed, after the title, with a 6pt swatch; a nested row omits it when it equals its parent's. A host pane has nothing.
