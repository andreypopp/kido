koa — width, user messages, agent lines, @names

Four refinements of the shipped page (share/koa/page), on mockup.html's language. 1: the composer's text edge equals the transcript's. 2: six treatments of the user message, to choose from. 3: a message between agents is one line, like a job line, and its body opens on a click. 4: every @name is a link to that agent's pane.

1 · The composer's width: its text edge is the transcript's

Shipped, the transcript's text is 680pt wide (720 − 2×20) and the user block reaches 12pt past it on each side (704); the composer's field is 672 (720 − 2×24) and its text 648, so the field sits 16pt inside the user block and the text 16pt inside the assistant's. Aligned: the composer takes the transcript's side padding minus the user block's pad (8pt; 4pt in the narrow pane), and the field's own padding is that pad (12pt; 8pt narrow), so the field's edges are the user block's and its text edge is the transcript's. The dashed lines are the transcript's text edges.

shipped: the field is 16pt in from the user block, its text 16pt in from the answer

aligned: the field is the user block's width; its text starts where the answer's does

2 · The user message: six treatments

The picker above switches all panes. A: the shipped 18% accent tint, full width. B: a chat bubble at the right, at most 82% wide, the time under it. C: no fill, a 2pt accent bar at the left, the text where the answer's text is. D: the composer's own card (background, hairline, the composer's radius), so the message looks like the field it was typed in. E: no block; the text is the heading of what follows, 600, a hairline under the message. F: the accent itself, with the page's background as ink. Each with a short message, a long one with a quote and code, and one with attachments.

3 · A message between agents is one line

Outgoing and incoming alike: kind to|from @name relation, then the start of the body, ellipsized, and the time at the right; the same line as a job notice and a run, in the transcript's muted tone. A click opens the body under it, indented with a hairline like a run's steps; a second click closes it. A refused call or a failed spawn colours the kind and the body red. With the chevron, the line is a run's; without it, the name is the handle. The second pane has two open.

4 · @name is a link to the agent's pane

Wherever an agent is named (an agent line's name, a @name in the answer's or the user's text, a list_agents step), the name is 600 in the text's colour, with no underline; on hover it takes the accent and a hairline underline, and the pointer is a hand. A click focuses that agent's pane, as a sidebar click does. koa links a @name in prose only when the name is an agent of the ko-pi registry at render time; a name that matches no agent stays text. An agent that has ended keeps its 600 weight in the muted tone and is no link (the cursor here is on @sidebar-right in the answer).
