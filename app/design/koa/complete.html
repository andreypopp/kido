koa — the completion popup

The popup of the CodeMirror composer (plans/koa.md, section 7, "Completion"), above the floating glass composer. It uses the dock's glass, hairline and shadow, rows of a terminal-font label and a muted detail, the current row on the 8% well, at most 8 rows before it scrolls. / completes the commands of get_commands (extension commands, prompt templates, skills) with the description as the detail and the kind at the right; @ completes the agents of the session (as ko-pi shows them) first and then files and directories from fd. Keys: ↑↓ move, Tab accepts, Enter accepts (and sends for a command), Escape closes. Nothing here is a product change yet; it is the reference for unit 11.

Click a row to make it current.

1 · / typed at the start: every command

The list is the whole command set, templates, skills and extension commands together, in get_commands order; the kind sits at the right in the faint tone. Ten commands, eight visible, the list scrolls. The first row is current.

2 · /re: the fuzzy filter

pi's fuzzy filter over the names; a skill: name matches by its bare name first. The matched letters of a command or agent name are bold; file paths are plain. Enter on a command accepts /release and sends.

3 · @si: agents, then files

The agents of the session whose name starts with the token come first, each as ko-pi shows it: @name, then its status, activity and parent in the muted detail; the inserted text is @name (session 9702ddd1) . The files that fd finds follow under the same prefix; a directory ends with / and inserts without a trailing space.

4 · @ko_s: files alone

No agent matches, so the list is files and directories only, the base directory's own entries first, then the deeper matches, 20 at most, 8 visible.

5 · @ in the middle of a message, with text after the cursor

The popup opens at the token, not at the field's edge, and stays inside the field's width. Here the second agent row is current.

6 · No match

An empty answer closes the list: @zzz shows no popup, no "no results" row. The plan has no empty state, so none is drawn.
