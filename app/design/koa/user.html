koa — the user message

One block: the accent at 18% over the background (user, 2026-11-10), radius 8pt, padding 7pt 12pt, the text in --fg as prose, the time at the top right in the accent ink (the accent mixed 60% toward the foreground, .8em terminal font, tabular digits). Nothing in the block is gray: a quote, a path, inline code, a code block all take an accent mix, because the gray mixes read as dirty over the tint. Every state below, light and dark, wide and narrow.

1 · One line, and several paragraphs

The time floats at the right of the first line; the text wraps under it. A message is Markdown as the user typed it: paragraphs, a list, inline code. Inline code takes the accent at 12% over transparent in place of the gray well.

2 · A quote: ⌘O on a selection, or a question control

The quote lines (> ) render as a blockquote: the text in the accent ink, the same as the time; the 2pt bar in the accent at 45% over transparent. The answer under it is the message's own text in --fg. Left: one quoted question and its answer (a question control). Right: a terminal selection quoted with ⌘O and a question about it; two quotes in one message.

3 · A code block, and attachments

A fenced block inside the user message: the accent at 10% over transparent with a 30% accent edge, the text in --fg, no language label. Attachments (media.html, approved): the thumbnails as sent, and the paths under the text in the terminal font, in the accent ink, not gray.

4 · Long

A long message is a long block; nothing folds (the user wrote it and sees it whole). The time stays at the top right.
